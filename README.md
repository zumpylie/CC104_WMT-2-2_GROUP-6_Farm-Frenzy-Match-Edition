FARM FRENZY: MATCH EDITION 

CC104 – Data Structures and Algorithms Final Project

Farm Frenzy: Match Edition is a browser-based memory matching game inspired by farm animals. Players must find identical animal pairs by flipping two cards at a time. The objective is to match all animal pairs using as few attempts as possible.

Game Overview
Game Title: Farm Frenzy: Match Edition
Game Type: Memory Matching Game
Course: CC104 – Data Structures and Algorithms
Section: WMT 2-2
Group: 6
Platform: Web Browser

Game Objectives

1. Find all identical animal pairs.
2. Improve memory and concentration.
3. Complete the game using as few attempts as possible.
4. Understand how arrays and algorithms work through interactive gameplay.

Game Features

- 12 animal cards arranged in a 4 × 3 grid.
- 6 pairs of farm animals.
- Interactive card flipping.
- Automatic comparison of selected cards.
- Matched cards remain revealed.
- Unmatched cards flip back after a short delay.
- Attempts counter.
- Matched pairs counter.
- Victory notification.
- Restart button with a shuffled deck.
- Leader Board Ranking.

Data Structures and Algorithms

This project demonstrates the following Data Structures and Algorithms concepts:

| Concept | Application |
|---|---|
| Arrays | Store animal card values. |
| Shuffling | Randomize the arrangement of cards. |
| Array Traversal | Process and display the cards. |
| Searching | Identify selected cards. |
| Equality Comparison | Determine whether two cards match. |
| Loops | Generate and process the cards. |

Shuffling Algorithm: Fisher–Yates Shuffle will be used to randomize the animal cards.

How to Play

1. Open the game in your web browser.
2. Click any animal card to reveal it.
3. Select a second card to find its matching pair.
4. If the two cards match, they remain revealed.
5. If they do not match, they will automatically flip back.
6. Continue matching until all six pairs are found.
7. Complete all pairs to win the game!
8. Click the Restart button to play again.
9. Check the Leader Board for Ranking.
